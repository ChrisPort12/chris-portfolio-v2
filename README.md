## 📖 About the project

CHRIS.DEV is a professional software developer portfolio designed to
showcase my technical skills, professional experience, education,
certifications and software development projects.

This project also represents my learning journey into modern
frontend development using React, TypeScript and other
web technologies.

## 🎨 Design concept

Modern Bento Developer Portfolio.

The visual identity combines three design approaches:

- **60% Bento Grid:** inspired by Apple and Notion.
- **20% Minimal Editorial:** clean typography and visual hierarchy.
- **20% Executive Developer:** premium technological aesthetics.

## Theme System

The portfolio includes a dynamic and accessible theme system
designed to provide a consistent user experience.

- Light, dark, and system appearance modes.
- Persistent preferences using localStorage.
- Automatic detection of system color scheme.
- Real-time response to system appearance changes.
- Reusable useTheme custom hook.
- Accessible ThemeSwitcher component.
- Lucide React icons.
- Early theme initialization to prevent incorrect theme flashes.
- Error handling for restricted browser storage.


## 🚀 Getting started

### Requirements

- Node.js 22.12+ or a compatible newer version
- npm
- Git

### Installation

```bash
git clone https://github.com/ChrisPort12/chris-portfolio-v2.git
cd chris-portfolio-v2
npm ci
npm run dev
```

Open the local URL displayed in your terminal.

## 📦 Available scripts

| Command | Description |
| --- | --- |
| npm run dev | Start development server |
| npm run build | Build for production |
| npm run lint | Analyze code quality |
| npm run preview | Preview production build |

## 🌱 Development workflow

- `feature/*`: individual features.
